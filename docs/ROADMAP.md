# ROADMAP

## Phase 0 — Foundation
- Confirm the founder specification and core product scope.
- Create repository structure and documentation.
- Establish the basic architecture for local capture and processing.

## Phase 1 — Capture MVP
- Build a simple iPhone app flow with Start Visit and Finish Visit.
- Enable room capture and microphone recording.
- Send capture data to the local backend.

## Phase 2 — Measurement and Understanding
- Process room scan data into structured measurements.
- Convert conversation into structured requirements and notes.
- Validate the quality of the generated outputs on real visits.

## Phase 3 — Draft Estimate
- Apply company profile assumptions to generate a draft estimate.
- Produce paint quantity, labour, materials, and suggested quotation.
- Ensure the output is clearly advisory and reviewable.

## Phase 4 — Reliability and Polish
- Improve error handling and capture reliability.
- Refine the user experience for painters.
- Add logging, quality checks, and iteration support.

## Phase 5 — Expansion
- Revisit provider flexibility and possible future deployment options.
- Consider whether the product should expand beyond the initial painting-company use case.

This roadmap keeps the initial focus on proving the core workflow before adding complexity.
